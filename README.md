# MediConnect

Sistema de Gestión de Citas Médicas desarrollado con arquitectura Full Stack MEAN.

## Tecnologías

- Angular
- Node.js
- Express
- MongoDB
- MongoDB Atlas
- JWT
- bcrypt
- GitHub
- Railway

## Funcionalidades

- Registro de usuarios
- Inicio de sesión
- Autenticación mediante JWT
- Control de roles
- Gestión de usuarios
- Gestión de pacientes
- Gestión de doctores
- Gestión de especialidades
- Gestión de citas
- Gestión de historiales médicos
- Gestión de recetas
- CRUD completo
- Búsqueda de registros
- Rutas protegidas
- HTTP Interceptor
- Despliegue en la nube

## Roles

### Admin
Control total del sistema.

### User
Acceso a las funcionalidades permitidas del sistema.

### Guest
Acceso limitado.

## Backend

Node.js + Express + MongoDB Atlas.

Puerto local:

http://localhost:8080

## Frontend

Angular SPA.
